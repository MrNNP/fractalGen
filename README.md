This is a demo of a feature proposal for a research project I was a part of at NJIT. The project involved multiple autonomous robots that drove on a whiteboard which had a projector pointed at it. 
The robots are able to independently calculate their global position based on the information broadcast from the projector. Each robot has a color sensor on it which is used to record the sequence of colors it sees. The sequence of color is then used to calculate an upper and lower bound on the global X and Y position of the robot on the board.
